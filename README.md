# EstudosPython

Repositório com exercícios e atividades feitos durante os estudos de Python — da lógica básica às atividades da faculdade.

## 📂 Conteúdo

| Pasta | Descrição |
|---|---|
| `mundo1-python/` | Exercícios de fundamentos da linguagem (variáveis, tipos, entrada e saída) |
| `condicionais-encadeadas/` | Exercícios com estruturas condicionais encadeadas (`if` / `elif` / `else`) |
| `laços-gerais/` | Exercícios com laços de repetição (`for` e `while`) |
| `exercicios-faculdade/` | Atividades e exercícios propostos na faculdade |

## 🛠️ Requisitos

- Python 3
- Dependências extras usadas em exercícios específicos, listadas em `requirements.txt` (Flask e bibliotecas relacionadas)

## ▶️ Como usar

```bash
git clone https://github.com/Gabrielrlp/EstudosPython.git
cd EstudosPython
pip install -r requirements.txt
```

Depois é só entrar na pasta do exercício desejado e rodar o arquivo `.py` correspondente.
